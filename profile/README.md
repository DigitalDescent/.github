---

We're Digital Descent, an independent game studio making games that bring people together. This is the home for our open source work: things we make along the way and share so others can use them too.

If something here saves you an afternoon, helps you get an idea off the ground, or gives you a useful starting point, we're happy it's found you.

### Have a look around

Browse the projects below to see what we're working on. Each repository has its own README with the details on what it does and how to get started. Check its license if you'd like to use it in your own work.

### Make something with us

Found a bug? Have an idea? We'd like to hear it. Open an issue in the relevant project, or send a pull request if you've got a change to share. Small fixes, clearer docs, and useful feedback all help.
